# Local fonts

Lora for book titles and headings; Nunito Sans for the interface. Latin and Latin Extended subsets cover Czech text. Served locally with no runtime font provider requests.

- @fontsource-variable/lora 5.3.0: SIL Open Font License; downloaded from npm and verified against its published sha512 integrity.
- @fontsource-variable/nunito-sans 5.3.0: SIL Open Font License; downloaded from npm and verified against its published sha512 integrity.
